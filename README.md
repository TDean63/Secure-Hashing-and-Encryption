# Secure-Hashing-and-Encryption

This Python Program demonstrates basic cryptography concepts using SHA-256 hashing and a Caesar cipher.

The program allows the user to generate a SHA-256 hash from either text or a file. It uses Python’s built in hashlib library to create the hash. File hashing can be used to help check file integrity because changing the file would result in a different hash.

The program also includes a Caesar cipher that can encrypt and decrypt text. The user enters a message and chooses a shift amount. Encryption moves each letter forward through the alphabet, while decryption reverses the shift. Spaces, numbers, and punctuation are left unchanged.

A simple menu allows the user to choose between hashing text, hashing a file, encrypting a message, decrypting a message, or exciting the program.
